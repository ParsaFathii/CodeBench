## وابستگی‌های شخص ثالث

CodeBench بر شانه ابزارهای متن‌باز ایستاده است. این بخش‌ها **زیر مجوزهای خودشان**
توزیع می‌شوند و متن مجوز هر پروژه در مخزن رسمی آن موجود است. استفاده از CodeBench
به معنای پذیرش مجوزهای این وابستگی‌ها هم هست.

### هارنس‌ها و ابزارهای اندازه‌گیری

| مؤلفه | نقش در CodeBench | مجوز |
|---|---|---|
| Google Benchmark (نسخه v1.9.4) | هارنس اندازه‌گیری C++ | Apache License 2.0 |
| JMH — Java Microbenchmark Harness (1.37) | هارنس اندازه‌گیری Java | GPLv2 with Classpath Exception |
| pyperf (2.10.0) | هارنس اندازه‌گیری Python | MIT |

نکته درباره JMH: کدهای مربوط به JMH از CodeBench جدا هستند — چهار فایل jar زیر
`engines/java/lib/` صرفاً به‌صورت باینری (بدون هیچ تغییری) commit شده‌اند تا موتور
Java بدون مرحله دانلود خودکفا باشد:

| فایل | پروژه | مجوز |
|---|---|---|
| `jmh-core-1.37.jar` | OpenJDK JMH | GPLv2 with Classpath Exception |
| `jmh-generator-annprocess-1.37.jar` | OpenJDK JMH | GPLv2 with Classpath Exception |
| `jopt-simple-5.0.4.jar` | jopt-simple | MIT |
| `commons-math3-3.6.1.jar` | Apache Commons Math | Apache License 2.0 |

Classpath Exception مربوط به GPLv2 به کد‌های مستقل که فقط از طریق API با کتابخانه
ارتباط دارند، اجازه می‌دهد تحت مجوز دلخواه خودشان باقی بمانند؛ کد CodeBench فقط
JMH را فراخوانی می‌کند و آن را در خود ندارد.

### toolchain و زمان اجرا

| مؤلفه | نقش | مجوز |
|---|---|---|
| Temurin JDK 21 (Eclipse Adoptium) | کامپایل و اجرای موتور Java | GPLv2 with Classpath Exception |
| g++ / GCC | کامپایل موتور C++ | GPLv3 (با استثنای رانتایم GCC) |
| CPython 3.12 | اجرای موتور Python | PSF License (BSD-سبک، سازگار با GPLv2) |
| cmake | build کردن Google Benchmark | Apache License 2.0 |

سورس و build محلی Google Benchmark در پوشه `.cache/` نگه داشته می‌شود که
gitignore شده است و بخشی از توزیع پروژه نیست.

### اکوسیستم وب

لایه وب بر پایه ابزارهای استاندارد این اکوسیستم ساخته شده — از جمله Next.js
(‌MIT)، ‏React (MIT)، ‏Prisma (Apache-2.0)، ‏Tailwind CSS (MIT)، ‏Radix UI
(‌MIT)، ‏TanStack Query (MIT) و zod (MIT) — که همگی هنگام `bun install` نصب
می‌شوند و فهرست دقیقشان با نسخهها در `package.json` قابل مشاهده است.

### لایه هوش مصنوعی (اختیاری)

ارائه‌دهنده‌های پشتیبانی‌شده — ‏z-ai-web-dev-sdk و Ollama (MIT) — هنگام استفاده
فعال می‌شوند؛ لایه هوش مصنوعی کاملاً اختیاری است و با گزینه `disabled` کل
پلتفرم بدون آن کار می‌کند.

## مسئولیت‌های هنگام توزیع مجدد

اگر نسخه‌ای از CodeBench را بازتوزیع می‌کنید:

1. فایل `LICENSE` مربوط به مجوز Apache-2.0 را همراه کد نگه دارید و اعلان حق نشر
   «Copyright © 2026 Parsa Fathi» را در نسخه‌های مشتق‌شده حفظ کنید.
2. اگر کد را تغییر داده‌اید، تغییرات را صریح و قابل تشخیص نشان دهید (مثلاً در
   فایل‌های تغییر‌یافته یا در NOTICE/توضیحات توزیع خودتان).
3. jarهای موجود در `engines/java/lib/` را دست‌نخورده و با احترام به مجوزهای جدول
   بالا منتقل کنید؛ این فایل‌ها باید همان نسخه‌های باینری اصلی بمانند.
4. مستندات و گزارش‌های نمونه را همراه با یادآوری اینکه نتایج مختص محیط ثبت‌شده
   است، منتقل کنید.

## استناد به پروژه

اگر در پژوهش، مقاله یا مستندات خودتان از CodeBench یا گزارش‌های تولیدشده با آن
استفاده می‌کنید، لطفاً به مخزن پروژه ارجاع دهید:

```bibtex
@software{codebench2026,
  author = {Parsa Fathi},
  title  = {CodeBench: Cross-Language Algorithm Benchmarking and Performance Analysis Platform},
  year   = {2026},
  url    = {https://github.com/ParsaFathii/CodeBench},
  note   = {Apache License 2.0}
}
```

هنگام نقل اعداد تولیدشده با CodeBench، این نکته را که در سراسر مستندات تکرار
شده رعایت کنید: نتایج مختص محیط ثبت‌شده در گزارش‌اند و رتبه‌بندی جهانی زبان‌های
برنامه‌نویسی نیستند؛ snapshot محیط را همراه اعداد نقل کنید.
